## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mzb000/web-dev-journey.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd web-dev-journey
   ```

3. **Open any HTML file:**
   - Double-click any `index.html` file to open it in your browser.
   - Or use VS Code with the **Live Server** extension.
